# WRAD ARMS — connected first-person hands and arms

- Artist: wriks / wwwriks
- Source: https://github.com/wwwriks/wrad-arms
- Asset page: https://wriks.itch.io/wrad-arms
- License: CC0 1.0 Universal (included as LICENSE)
- Original asset: arms.glb, downloaded 2026-10-08, 456,328 bytes

The original mesh, texture and armature are retained. The game poses the original
finger bones around the existing tool handles, selects the left or right arm,
and bakes that pose once to a static mesh. Each connected arm is 598 triangles
and one draw call. No hand or arm geometry was authored for this integration.
