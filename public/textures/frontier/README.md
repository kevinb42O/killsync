# Frontier PBR surfaces

Real, locally bundled 1K JPEG PBR maps from ambientCG. All three assets are
released under CC0 1.0 Universal. No runtime download or API key is required.

| Asset | Purpose | Source |
| --- | --- | --- |
| Ground037 | Grass-tinted ground, soil, trail surfaces | https://ambientcg.com/view?id=Ground037 |
| Rock030 | Excavation faces, copper/iron seams, stone construction | https://ambientcg.com/view?id=Rock030 |
| WoodFloor051 | Timber construction | https://ambientcg.com/view?id=WoodFloor051 |

For each asset: Color, NormalGL and Roughness maps from its official
`1K-JPG.zip` archive. Downloaded 2026-10-05. License information:
https://docs.ambientcg.com/license/

The frontier trees and bushes use the new Quaternius CC0 GLB assets.
The grass, rocks and settlement props use bundled Kenney CC0 GLB assets; their original License.txt files are under
`public/models/friends/`. No third-party premade map is bundled.
