# Hellbinder casting hand

`right-hand.glb` is the authored, skinned right-hand mesh from the Immersive Web
WebXR Input Profiles assets, distributed under the MIT license in `LICENSE.txt`.

- Source: https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets/profiles/generic-hand
- Download: https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/right.glb
- License: https://github.com/immersive-web/webxr-input-profiles/blob/main/packages/assets/LICENSE.md
- Copyright (c) 2019 Amazon

The original binary is preserved. In game, its 25 joints are reorganized into
finger chains while preserving the bind pose, posed into a relaxed casting hand,
and given a skin material. A continuous tailored sleeve and wrist cuff join the
hand to a shoulder behind the first-person camera. Spell effects sit above the
palm. The asset is served locally; gameplay has no third-party model dependency.
